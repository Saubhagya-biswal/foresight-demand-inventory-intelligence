# FORESIGHT: Demand & Inventory Intelligence

An end-to-end Data Science project for retail demand forecasting and inventory intelligence.

## Business Problem

Retail businesses need to answer:

- How much demand can we expect in the future?
- Which products have a stockout risk?
- Which products are overstocked?
- What action should be taken?

FORESIGHT predicts product demand and provides inventory risk insights.

## Project Workflow

1. Business Understanding
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis
5. Feature Engineering
6. Baseline Forecasting
